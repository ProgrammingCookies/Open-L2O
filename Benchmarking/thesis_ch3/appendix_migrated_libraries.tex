\chapter{Migration of the Open-L2O libraries}
\label{app:migration}

The Open-L2O code release~\cite{chen2021primer} consists of six independent
libraries written for TensorFlow~1 (graph mode, \texttt{tf.contrib},
per-library dependency pins). Before the platform of Chapter~\ref{ch:platform}
could exist, each library was ported to TensorFlow~2 with Keras~3 and eager
execution so that all of them run in one environment. The port was
deliberately mechanical: every training and evaluation script keeps its
original name, existing flags and output files, the model architectures and
meta-training loops are unchanged, and optional research features that no
published command exercises (model-transfer distillation, curriculum
learning, hardware-specific measurement paths) were left out rather than
re-invented. Each library was verified after the port by running its own
documented training and evaluation commands end to end.
Table~\ref{tab:migrated-libraries} lists the libraries and what changed
structurally in each. The PyTorch library in the release (L2O-Minimax) was not
part of the migration and is not used in this thesis.
